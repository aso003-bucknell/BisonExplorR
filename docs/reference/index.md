# Package index

## For students

The three functions a student needs. Everything else on this page is
instructor-facing.

- [`launch_graded_tutorial()`](https://aso003-bucknell.github.io/BisonExplorR/reference/launch_graded_tutorial.md)
  : Open the graded (credit-bearing) version of a tutorial
- [`get_lab()`](https://aso003-bucknell.github.io/BisonExplorR/reference/get_lab.md)
  : Copy an in-lab R script into your project
- [`get_practice_exam()`](https://aso003-bucknell.github.io/BisonExplorR/reference/get_practice_exam.md)
  : Copy a practice exam's datasets into your project

## For instructors

Grading and course administration.

- [`grade_module()`](https://aso003-bucknell.github.io/BisonExplorR/reference/grade_module.md)
  : Grade a BisonExplorR tutorial module from logged responses

## The Coach

Socratic hint UI embedded in tutorials. These are called from tutorial
`.Rmd` files, not from the console. The Coach requires a server-side
proxy; without one it falls back to static offline nudges.

- [`coach_ui()`](https://aso003-bucknell.github.io/BisonExplorR/reference/coach_ui.md)
  : BisonExplorR Coach user interface
- [`coach_server()`](https://aso003-bucknell.github.io/BisonExplorR/reference/coach_server.md)
  : BisonExplorR Coach server
